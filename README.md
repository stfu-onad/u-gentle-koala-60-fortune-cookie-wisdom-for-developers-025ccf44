A Python program that writes one original fortune-cookie line for a software developer — at most 120 characters — to `/output/entry.txt`, for make.fun's "Fortune Cookie Wisdom for Developers" bounty. The fortune: a quiet deploy on Friday is worth more than a loud apology on Monday.

## Run it

```sh
python3 main.py
```
